# Anson6118 的個人專屬主頁 (Personal Homepage)

這是一個現代化、具備沉浸感深淺色主題切換與動態即時時鐘的個人主頁網頁專案。

## ✨ 特色亮點

- 🎨 **現代化視覺設計**：深色/淺色主題切換、背景流體漸變動態光暈、毛玻璃（Glassmorphism）卡片視覺效果。
- 🕒 **動態時鐘與問候**：依據當前時間自動切換問候語（早安/午安/傍晚好/夜深了）與動態時鐘顯示。
- ✏️ **互動式個人資訊**：可直接在瀏覽器上點擊編輯個人姓名、簡介，並支援切換頭像 Emoji。
- 📱 **響應式排版**：完美適配桌面螢幕、平板與手機等各種設備。
- 🚀 **純粹無相依**：使用原生 HTML5、CSS3 與 JavaScript，載入速度極快，非常適合使用 GitHub Pages 進行託管。

## 🛠️ 技術棧

- **HTML5**: 語意化結構
- **CSS3**: CSS 變數、Flexbox / Grid、CSS 動畫
- **JavaScript (ES6+)**: 原生 DOM 操作與時間動態渲染

## 🌐 部署方式 (GitHub Pages)

1. 推送本專案至 GitHub 倉庫的主分支 (`main`)。
2. 在 GitHub 倉庫中進入 **Settings** > **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 `Deploy from a branch`。
4. Branch 選擇 `main` 分支並選擇根目錄 `/ (root)`，點擊 **Save**。
5. 稍等數十秒即可透過 `https://Anson6118.github.io/<專案名稱>/` 瀏覽您的網站！
